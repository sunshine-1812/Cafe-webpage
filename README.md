# ☕ Café Webpage

A simple and responsive café website designed using **HTML, CSS, and Bootstrap**.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## ✨ Features
- Responsive navigation bar
- Café menu section
- Food and beverage sections
- Attractive and responsive layout
- Bootstrap components and utilities

## 🎯 Purpose
This project was created to practice frontend web development and build a clean, responsive café website.
